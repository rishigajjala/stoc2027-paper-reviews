One primary topic per paper, based on principal theorem, not all applications. All counts are our classifications, not official topic counts or caps. Record ambiguous cases with a note.
Quantum-specific theorems (including quantum cryptography, codes, query bounds, tomography) -> quantum. Classical extractors secure against quantum side information may remain complexity if construction is classical and quantum aspect secondary.
Classical cryptography and differential privacy -> crypto_privacy, including private learning. Classical coding constructions/decoding and network coding -> coding_info, including decoding hardness; quantum codes -> quantum.
Online algorithms AND online learning/bandits/regret -> online. Dynamic algorithms are data_sublinear, NOT online. Mechanism design with strategic agents -> economics; prophet/secretary/matching without incentives -> online.
Circuits, proof complexity, communication complexity, pseudorandomness, PCP, fine-grained hardness, counting dichotomies -> complexity. Algebraic circuit lower bounds/PIT -> complexity.
Offline learning/distribution testing/inference/sample estimation -> learning. Graph/general property testing -> data_sublinear.
Approximation ratios, continuous/convex optimization, combinatorial optimization such as submodular/bin packing -> approx_opt. Pure static graph algorithms (cuts/paths/matching), exact/parameterized discrete/string algorithms -> graph_discrete. Dynamic/streaming algorithms, oracles and data structures -> data_sublinear.
Counting/sampling algorithms and mixing bounds -> counting_sampling. Structural graph/extremal/discrepancy/metric-embedding/convex-geometry theorems -> combinatorics_geometry.
Polynomial/matrix arithmetic, number theory and lattice algorithms -> algebra_number. Distributed/parallel computational models -> distributed, unless primarily quantum. Pure multithreaded speedup is not automatically distributed if not central.
Use title and program session for historical papers, read abstract for ambiguity when needed. Use review area/summary for current candidates. Borderline cases are coarse classification uncertainty, not grounds for acceptance predictions.
